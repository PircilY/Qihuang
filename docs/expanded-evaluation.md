# EXPANDED 自监督检索评测

## 结论可信度

|结果|可信度|理由|
|---|---|---|
|标题类|较可信的检索代理证据|查询和目标来自原始标题，但仍为标题词面自监督，不是人工相关性判断。|
|术语类，词典目标|设计验证；循环风险|查询扩展与目标构造共用词典；提升仅说明扩展按设计工作，不能证明检索能力。|
|术语类，中文原文目标|较可信的检索代理证据|目标判定只查文档原始字段中的中文术语，不使用扩展出来的英文词。|
|真实医学相关性|未验证|没有人工相关性标注或独立 judge。|

固定种子42，K=4，1000次样本 bootstrap 百分位95%区间。未读取 holdout 或原50题。

总样本 2522；标题同语言 398、标题跨语言 0；词典目标术语同/跨语言 736/812；中文原文独立目标术语 576。标题样本只由标题构造；中文原文组不使用扩展出来的英文词判定目标。

V0–V3 通过真实 Python `LlamaIndexEngine.query` 执行，默认 SHA-256 hash 向量；before 读取 `c9652d3`（本地没有 `delivery-c9652d3` 标签）的 G/H 前 EXPANDED 快照并关闭查询桥接，after 使用工作区重建语料并启用桥接。元数据排序权重为 0。结果是实际检索策略的自监督代理结果，不是人工评审。
