## A：同步和持久化

- 修订号只包含 BASELINE 运行时导入文档；种子与 EXPANDED 不参与。空集合统一为 SHA-256 空串摘要。EXPANDED 修订号为空且无需同步。
- 409 处理比较运行时清单；远程有多余文档时 reload 后整批补发，健康接口确认修订号后才标记 IN_SYNC。同步锁配合世代计数避免同一轮并发 409 重复补发，同时允许远程重启后的下一轮补发。
- 导入先强制落盘 JSONL 追加日志再发布内存；按累计导入数量为 2 的幂时原子合并快照，避免每次全量重写。重启回放允许检查点重复记录；不完整尾记录截断，完整损坏记录导致启动失败。合并失败保留已落盘日志。旧 JSON 快照仍可读取。
- 默认运行时总量上限：1000 文档、10000000 正文字符；可配置。反向代理使用 Spring framework 转发头解析，代理必须在入口覆盖客户端转发头。

- 限流默认：Java 导入 30 次/分钟、评测 2 次/分钟；Python 共享导入/重载入口 60 次/分钟。单进程固定窗口按客户端和操作计数，拒绝返回 429/Retry-After；评测单次最多 200 题且单并发。容器多实例需在入口统一限流。
- 并发同步旧测试顺序抛两次 409 不保证请求同时进入，改用屏障显式制造同轮 409；仍严格要求只补发一次，没有放宽验收。

- 健康测试原先要求种子 document inventory 非空；按 A.2 明确要求修订号/清单只统计运行时导入，改为断言启动时空清单。健康文档总数仍包含种子，未减少安全或检索断言。

- 原 50 题评测及性能测量使用显式 researchReport 开关；默认测试不产生评测报告、不访问留出集。性能报告记录实测毫秒，不使用估算。

- Python 修订号重启测试的清单预期同样改为空；新增测试覆盖导入后清单和修订号，保持未变化种子同步的幂等兼容，拒绝修改种子正文。

- 评测问题正文累计上限默认 100000 字符，可通过 EVALUATION_MAX_CHARACTERS 配置。并发修改导入库时，已响应请求只确认其请求携带的修订号；评测入口重新对比当前修订号与确认状态。
