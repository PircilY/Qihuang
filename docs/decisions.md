## A：同步和持久化

- 修订号只包含 BASELINE 运行时导入文档；种子与 EXPANDED 不参与。空集合统一为 SHA-256 空串摘要。EXPANDED 修订号为空且无需同步。
- 409 处理比较运行时清单；远程有多余文档时 reload 后整批补发，健康接口确认修订号后才标记 IN_SYNC。同步锁配合世代计数避免同一轮并发 409 重复补发，同时允许远程重启后的下一轮补发。
- 导入先强制落盘 JSONL 追加日志再发布内存；按累计导入数量为 2 的幂时原子合并快照，避免每次全量重写。重启回放允许检查点重复记录；不完整尾记录截断，完整损坏记录导致启动失败。合并失败保留已落盘日志。旧 JSON 快照仍可读取。
- 默认运行时总量上限：1000 文档、10000000 正文字符；可配置。反向代理使用 Spring framework 转发头解析，代理必须在入口覆盖客户端转发头。

- 限流默认：Java 导入 30 次/分钟、评测 2 次/分钟；Python 共享导入/重载入口 60 次/分钟。单进程固定窗口按客户端和操作计数，拒绝返回 429/Retry-After；评测单次最多 200 题且单并发。容器多实例需在入口统一限流。
- 并发同步旧测试顺序抛两次 409 不保证请求同时进入，改用屏障显式制造同轮 409；仍严格要求只补发一次，没有放宽验收。

- 健康测试原先要求种子 document inventory 非空；按 A.2 明确要求修订号/清单只统计运行时导入，改为断言启动时空清单。健康文档总数仍包含种子，未减少安全或检索断言。

- 原 50 题评测及性能测量使用显式 researchReport 开关；默认测试不产生评测报告、不访问留出集。性能报告记录实测毫秒，不使用估算。

- Python 修订号重启测试的清单预期同样改为空；新增测试覆盖导入后清单和修订号，保持未变化种子同步的幂等兼容，拒绝修改种子正文。

- 评测问题正文累计上限默认 100000 字符，可通过 EVALUATION_MAX_CHARACTERS 配置。并发修改导入库时，已响应请求只确认其请求携带的修订号；评测入口重新对比当前修订号与确认状态。

## B：分词、索引和评分

- 两端改为连续中文二元组与至少两字符的 ASCII 词，保留词频；分隔符之间不制造二元组。沿用既有有限别名，心衰同义词两端一致。Python 旧单字/三元组预期按 B.4 更新成二元组预期，新增重复词频和分隔符严格测试；原 50 题标签与 safety 预期未更改。
- Java 在启动/导入时预计算正文/疾病相关性特征、倒排表、全库 IDF、长度和 512 维哈希向量；仅变更文档重新分词。Python 使用相同 BM25 k1=1.4、b=.72 的倒排实现，LlamaIndex 保留向量索引；避免筛选后重算 IDF 或按过滤条件重复建 BM25。可解释地替换库内分词以实现契约一致，BM25 retriever 安装版本将在 F 记录。
- 哈希向量两端统一 SHA-256 特征桶和符号，默认仍为本地哈希后端，没有网络模型。V2 与 V3 均使用带权 RRF；各通道 chunkId 去重。normalizedFusion 开关保留旧加法模式，启用后除以理论双通道第一名上界，元数据只按比例乘入。
- 覆盖规则逐片段匹配共享正则，不跨片段拼接；共享规则内容不修改。拒答 confidence 统一 .2，表达证据支持度而非安全判断可信程度。英文/中文句末和换行切句，摘录最多 400 字。
- 证据等级加分仍保留；现有正式语料均未评级，不声称提升来自临床证据分级。

- 参数网格：metadataWeight={0,.05,.1,.2,.25,.5}、threshold={.3,.5,.6,.75,.9}，其他权重1/.85、K=4不变。先要求拒答准确率1，再最大化Hit@1和MRR；并列选更高阈值以保守处理证据，再选更小metadataWeight。选择0/.9：元数据加分没有改善此调参集，保留可配置实现，不伪称收益。阶段 B 明确要求标定，因此默认切换归一化模式和所选阈值；旧六参数构造保留旧评分用于兼容单元测试，线上可显式 RAG_NORMALIZED_FUSION=false、RAG_MINIMUM_EVIDENCE_SCORE=.016 恢复旧评分。
- 契约测试归一化最大RRF预期改成1，统一阈值预期改成.9，理由是B.3明确改变评分量纲；跨引擎拒答/Top1/重合门槛没有放宽。

- 新增跨片段覆盖测试最初问题词序未触发现有共享规则，修正测试问题使其触发既有规则；没有改正则或已有 safety 测试预期。

## E：生成对照实验

- `GENERATION_EXPERIMENT_ENABLED=false` 是默认值，关闭时没有实验路由。每次最多 50 题、每题 2000 字符、单实验并发，沿用研究接口限流与同源校验。请求上传问题 JSON，工具在客户端读取 JSON/JSONL；服务端不接受任意文件路径。
- 默认仅从原 50 题中选择 `shouldRefuse=false` 的 42 题，保留原标签。随机种子 42、temperature=0、max_tokens=2048；A/B 复用同一连接和参数，C 无模型。三模式按题依次执行，实测耗时不承诺随机可复现。
- A 保留急症和个体医疗请求拦截，没有检索上下文。A 模型拒答采用公开记录的短语启发式。B 使用原 ModelAnswerService；缺少引用或无效引用明确记为失败。失败保留行，回答为空且内容指标为零，另有 failureRate；拒答率与失败率分开。
- JUDGE_* 只用于独立评审连接，不继承生成连接的凭据；默认关闭。评审模型、完整提示、温度、是否同名生成模型和逐行评审失败均记录。未启用 judge 时 judgeSupport=0 是占位，不应解释为评审结论。
- 规则逐句支持要求该句全部引用编号有效且逐个由原文支持；不把不同证据合并来支持复合陈述。二元组只在连续字母/数字序列内计算，比例为回答唯一二元组在本行证据并集中的覆盖。无句子/无引用/无二元组分母为零时记零，不奖励空回答。
- Bootstrap 对每模式每问题行有放回抽样 1000 次，固定种子，输出均值与百分位 95% 区间。单题演示退化区间不代表研究结论；不同模式的时延包括其真实步骤，judge 时延不计入生成时延。
- 修复 CitationSupportEvaluator 的真实解析 bug：超长数字引用原来抛 NumberFormatException；连续无空格中文句子不分句；小数点可能分句。新增针对性断言，不改 safety-rules.json、既有安全断言或原 50 题标签。
