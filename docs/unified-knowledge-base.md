## 范围

概览、知识库、RAG 工作台、版本对比和检索流程统一请求 `corpus=COMBINED`，不再展示标准/扩充语料选择器。

| 范围 | 初始文档 | 初始片段 | 用途 |
| --- | ---: | ---: | --- |
| BASELINE | 4 | 11 | 原始标准资料与历史评测 |
| EXPANDED | 141 | 6810 | 核心及背景开放全文，排除隔离记录 |
| COMBINED | 145 | 6821 | 页面使用的统一知识库 |

这是按文档、片段编号合并的逻辑视图，没有改写或复制原始语料文件。相同编号优先标准语料；新增登记不能覆盖扩充库编号。运行时登记仍由原有持久化和同步协议管理，同时可在统一视图检索、查看原文，重启后恢复。扩充库仍是只读构建产物。

API 省略 `corpus` 仍默认 `BASELINE`，显式 `BASELINE`、`EXPANDED` 查询继续兼容。统一视图的运行时修订号与同步清单沿用标准语料，扩充构建文件不进入运行时同步。Java 和 Python 首次查询时按需建立统一索引；登记后使统一索引失效，下次查询刷新。

## 保持不变

- BASELINE 原文、原50题标签、留出集、冻结实验和共享安全规则。
- 默认 hash/BM25 检索、查询桥接关闭、不下载语义模型、不调用付费模型。
- 历史评测使用的语料范围和判定规则；统一索引会改变候选集与排序，不能复用历史成绩作为统一库成绩。
- 原文、来源、许可与隔离台账；统一展示不代表临床证据等级或医学正确性认证。

概览取消无信息量的 A 级占比环和单一来源百分比，改为文档年份分布与实际登记完整性（来源链接、正文校验值、访问日期）。登记统计只反映元数据，不宣称每个片段均可有效支持问答。
