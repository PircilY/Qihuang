边界与安全策略

系统只提供文献检索参考，不替代医师判断

  • 急症分流胸痛持续、呼吸困难等问题直接提示立即就医。
  • 拒答处方剂量不生成个体化克数、煎服与替代处方。
  • 证据不足不回答低于检索阈值时保留问题并说明无法判定。
  • 来源可追溯所有回答展示文档、版本、页码和原文引用。
