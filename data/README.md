# 来源与核验

`sources.json` 是种子语料的唯一维护入口。每个片段保留机构原文，不补写诊疗结论、统计数字、页码或临床等级。

## 校验

```powershell
python tools/build_corpus.py --check
python tools/build_corpus.py --cache-dir .tmp --check
```

第一条校验生成数据与清单的一致性；第二条同时核对每段摘录及章节标题是否存在于已下载的源 HTML。HTML 文件名来自 `cacheFile`，本机缓存位于 `.tmp`，不打包再分发。首次核验已在 2026-09-30 使用来源官网页面完成；后续页面可能更新，校验失败时应重新人工核对，不应绕过。

种子文档 SHA-256 基于所有收录摘录以两个换行连接后的 UTF-8 文本；片段 SHA-256 基于该片段原文。它们用于验证收录内容，没有声称是完整网页文件的哈希。用户导入文档的哈希基于正文统一 CRLF 为 LF、去除首尾空白后的 UTF-8 文本。

更新时先保存原网页、核对出版日期和许可，再更新清单及真实访问时间，执行不带 `--check` 的生成命令，检查差异并运行全部测试。禁止用推测的医学文字填补检索空白。

## 权限与时效

- WHO：署名短摘录用于文献核对，未声称取得全文再分发或商业许可。
- NIH/NCCIH：网页声明出版物属公有领域；保留署名，不包含图片，不暗示机构背书。
- 英文内容保持原文；人工中文标签仅供检索，不是经过医学复核的翻译。
- WHO 心血管页面标注 2021-06-11，但含后续更新；不依据该日期推断所有段落的年代。
- NCCIH 中医药页面标注 2019-04，不把它呈现为最新系统综述。
- 全部为健康信息资料而非经本项目临床评级的指南，证据等级一律「未评级」。
